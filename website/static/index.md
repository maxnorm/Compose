# Infrastructure for evolving onchain systems

Compose is a framework for building modular, maintainable smart contract systems with reusable facets, shared modules, and diamond architecture.

## Why Compose

- **Readable by design:** Keep each facet focused, self-contained, and understandable from top to bottom.
- **Diamond-native:** Build modular systems around ERC-2535 Diamonds and shared storage.
- **Composable architecture:** Assemble systems from focused facets and modules.
- **Structured tooling:** Scaffold a project with the Compose CLI and use Foundry or Hardhat workflows.
- **Built to evolve:** Add custom facets that work with Compose modules and shared diamond storage.
